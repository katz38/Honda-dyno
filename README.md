# Civic FN1 Dyno V2 - Dams Reprog

Web app GitHub Pages complète pour Honda Civic FN1.

## Modèles inclus

- Honda Civic FN1 1.8 i-VTEC
- Honda Civic FN1 2.2 i-CTDi

## Fonctionnalités

- Interface mobile type application iPhone
- Dyno GPS
- Puissance estimée
- Couple estimé
- Vitesse GPS
- 0-100 km/h
- 0-400 m
- 0-1000 m
- Historique des runs
- Comparaison des runs
- Graphiques puissance / couple
- Installation PWA sur iPhone et Android
- Lien Dams Reprog

## Publier sur GitHub Pages

1. Décompresse le ZIP.
2. Crée un dépôt GitHub, par exemple :

```text
civic-fn1-dyno
```

3. Envoie tous les fichiers à la racine du dépôt :

```text
index.html
style.css
app.js
README.md
manifest.webmanifest
sw.js
icon-192.png
icon-512.png
apple-touch-icon.png
favicon.png
```

4. Va dans :

```text
Settings > Pages
```

5. Mets :

```text
Source: Deploy from a branch
Branch: main
Folder: / root
```

6. Clique sur Save.
7. Attends 1 à 5 minutes.

Ton site sera disponible ici :

```text
https://TON-PSEUDO.github.io/civic-fn1-dyno/
```

## Installer sur iPhone

1. Ouvre l’URL avec Safari.
2. Appuie sur Partager.
3. Appuie sur Ajouter à l’écran d’accueil.

## Utilisation

1. Choisis ton modèle de Civic FN1.
2. Renseigne le poids conducteur + carburant + bagages.
3. Lance un run.
4. Accélère sur route privée ou fermée.
5. Arrête le run.
6. Enregistre les résultats.
7. Compare les runs.

## Important

Les résultats sont des estimations GPS, pas des mesures certifiées banc de puissance.

Utilisation uniquement sur route privée ou fermée.
